AI NEXTGEN — نسخه متصل به هوش مصنوعی

محتویات:
- index.html
- netlify.toml
- netlify/functions/chat.mjs

نکته مهم:
این بسته شامل رابط چت و تابع امن سرور است؛ پاسخ واقعی پس از ثبت کلید API در Netlify و انتشار همراه Functions فعال می‌شود.
کلید API را هرگز داخل index.html یا فایل‌های عمومی قرار نده.

راه‌اندازی:
1) این پوشه را به یک مخزن خصوصی GitHub اضافه کن و آن را به Netlify وصل کن.
   برای اجرای Netlify Functions، از انتشار پروژه همراه با پوشه netlify/functions استفاده کن؛
   صرفاً باز کردن index.html روی گوشی یا آپلود فقط خود فایل HTML کافی نیست.
2) در Netlify وارد Site configuration → Environment variables شو.
3) یک متغیر بساز:
   Key: OPENAI_API_KEY
   Value: کلید API که مدیر بزرگسال پروژه به‌صورت امن تهیه کرده است.
   Scope باید شامل Functions باشد.
4) در صورت نیاز متغیر اختیاری زیر را هم می‌توانی تعیین کنی:
   OPENAI_MODEL = gpt-5-mini
5) بعد از ذخیره متغیرها، سایت را دوباره Deploy کن.
6) سایت را باز کن و در بخش «چت هوش مصنوعی» یک پیام آزمایشی بفرست.

هزینه و امنیت:
- استفاده از API ممکن است هزینه داشته باشد و به اعتبار/صورتحساب حساب ارائه‌دهنده وابسته است.
- چون کاربر نوجوان است، تنظیم حساب، پرداخت و کلید API باید با کمک والد یا سرپرست بزرگسال انجام شود.
- کلید را در چت، تلگرام، HTML یا GitHub قرار نده.
- این نسخه تاریخچه گفتگو را در همان مرورگر (localStorage) نگه می‌دارد؛ هنوز ورود واقعی گوگل و همگام‌سازی ابری ندارد.
